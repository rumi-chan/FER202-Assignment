# FastFood – Web đặt đồ ăn nhanh (FER202)

React 18 + react-bootstrap + react-router-dom + axios, dữ liệu giả lập bằng json-server.

## Chạy project

```bash
npm install
npm run server   # terminal 1: json-server ở http://localhost:9999
npm start        # terminal 2: React ở http://localhost:3000
```
